# 分层架构设计文档：实验室管理系统
1. 技术底座：Java 21 / Spring Boot 3.4.1 / PostgreSQL 18
2. 分层约定：
   Controller——兑现 shared 契约接口，取租户、调服务、包响应，不写业务
   Service——业务规则与异常语义，租户号作第一个参数
   Repository——JPQL 查询封装，租户条件永在首位
   Entity——表结构映射，nullable 即需求表达
3. schema 治理：真源在 shared 契约仓，本仓 ddl-auto=validate 只校验不迁移
4. 核心数据模型：ER 草图（合同→接样单→样品→检测记录全链真实外键，
   删除行为沿链收敛：上游 RESTRICT 防孤儿，下游 CASCADE 随主归属清理；
   字典引用两档：参数/标准用 RESTRICT/SET NULL 硬外键，M04 码表用编码弱引用）
5. 设计原则：字符串主键 / 业务链表全租户列（平台级共享字典例外并说明理由）
6. 自检清单：每层职责一句话能说清 / 每条 SQL 首位带租户 / 每个字段能追溯到需求
